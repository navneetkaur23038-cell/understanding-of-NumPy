# understanding-of-NumPy
NumPy practice notebook covering arrays, indexing, slicing, reshaping, vectorization, masking, broadcasting, and numerical analysis.

A beginner-friendly Google Collab notebook demonstrating the fundamentals of **NumPy** and its use in numerical data analysis.

## Topics Covered

- 1D, 2D, and 3D arrays
- Array dimensions, shape, size, and data types
- Indexing and slicing
- Reshaping arrays
- `zeros()`, `ones()`, `arange()`, and `linspace()`
- Mathematical operations
- Vectorized operations
- Boolean masking
- Broadcasting
- Aggregate functions:
  - `sum()`
  - `mean()`
  - `min()`
  - `max()`
  - `median()`

## Tools Used

- Python
- NumPy
- Google Colab

## Purpose

This notebook is created for practicing NumPy concepts and building a strong foundation in Python-based numerical data analysis.
